# Buntly for Windows

Hold Right Ctrl, talk, let go. The words land where your cursor already was.
Speech runs on your PC. Audio is not saved. There is no account.

**Download:** [Buntly-Setup.exe](https://github.com/NithinRe/buntly/releases/latest)

64-bit Windows 10 or Windows 11. The installer does not ask for an administrator password.

Windows will say it protected your PC. This copy is not signed with a paid certificate.

1. Click **More info**.
2. Click **Run anyway**.

If you would rather not run unsigned software, stop. That is a fair choice.

Security software may also warn. Buntly has to notice the dictation key while another program is in front. It does not record your other keys.

The first launch downloads the speech model, about 1.6 GB, from Hugging Face. Internet is needed only for that download.

The full setup page is [WINDOWS-ONBOARDING.md](WINDOWS-ONBOARDING.md). That same page is inside the installer.

Transcription speed depends on the laptop and has not been timed on one yet. The first take after you open Buntly is slower while the model warms up.
